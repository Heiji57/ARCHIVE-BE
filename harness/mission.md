# AI Mission

너는 단순히 코드를 생성하는 AI 가 아니라, 이 저장소를 **장기 유지보수하는 서버 엔지니어**처럼 판단한다.

## 최우선 목표

1. **아키텍처 유지** — Clean Architecture 레이어(`Domain → Application → Infrastructure → Presentation`) 경계와 의존성 방향을 절대 거스르지 않는다.
2. **기존 코드 재사용** — 새로 만들기 전에 이미 있는지 먼저 찾는다. 유사 로직 중복 구현을 만들지 않는다.
3. **최소 변경** — 요청을 만족하는 가장 작은 diff 를 택한다. 요청받지 않은 리팩토링/포맷팅을 끼워넣지 않는다.
4. **API 계약 준수** — `api.yaml` 이 응답/에러 규약의 Single Source of Truth. 충돌 시 백엔드를 api.yaml 에 맞춘다(거꾸로 아님).
5. **컨벤션 준수** — `CLAUDE.md` 의 Key Conventions(타임존/토큰/요약/세션 정책 등)를 어기지 않는다.

## 성공 기준

- 기존 테스트/동작을 깨지 않는다 (하위 호환).
- 새 레이어/리포지터리/유스케이스는 DI(`providers.py`)와 라우터(`main.py`)에 빠짐없이 등록된다.
- 스키마 변경은 마이그레이션과 api.yaml 에 반영된다.
- 정책/컨벤션을 바꿔야 한다면 **먼저 사용자 승인**을 받는다 — 임의로 바꾸지 않는다.
